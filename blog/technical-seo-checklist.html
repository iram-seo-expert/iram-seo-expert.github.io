Technical SEO Checklist for 2026: 10 Things to Fix First

Technical SEO makes sure search engines can crawl, understand and load your site quickly. Use this checklist to find the problems that hold rankings back.

1. Check indexing in Search Console

Open Pages and see which URLs are indexed and why others are not. Look for accidental noindex tags and blocked pages.

2. Review robots.txt and your sitemap

Make sure robots.txt does not block important pages and lists your sitemap. Submit an XML sitemap that contains only canonical, indexable URLs.

3. Fix Core Web Vitals

Google's "good" targets are LCP of 2.5 seconds or less, INP of 200 milliseconds or less, and CLS of 0.1 or less. Compress images, avoid heavy scripts and reserve space for images to stop layout shift.

4. Make the site mobile friendly

Google mainly uses the mobile version of a page for indexing. Check text size, tap targets and that content matches the desktop version.

5. Use HTTPS everywhere

Serve every page over HTTPS and redirect HTTP versions with a 301.

6. Set canonical URLs

Each page should point to its preferred version to avoid duplicate content between variations such as www and non-www, or URLs with parameters.

7. Fix broken links and redirect chains

Crawl the site with a tool like Screaming Frog. Repair 404 pages and shorten redirect chains to a single step.

8. Add structured data

Use JSON-LD for Organization, Article, FAQ or Product where it fits, and validate it with Google's Rich Results Test.

9. Improve internal linking

Link related pages with descriptive anchor text so important pages are never more than a few clicks from the homepage.

10. Optimise images

Use modern formats such as WebP, set width and height, add useful alt text and lazy-load images below the fold.

Keep monitoring

Re-run these checks monthly in Search Console, GA4 and a crawler so problems are caught early.
